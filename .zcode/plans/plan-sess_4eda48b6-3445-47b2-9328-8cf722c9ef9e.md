## Pliki do utworzenia (11 szt.)

1. **`docs/README.md`** — indeks docsów + nawigacja dla zespołu.

2. **`docs/00-vision.md`** — pitch (problem: seniorzy pomijają leki, opiekun nie ma pewności; rozwiązanie: asystent głosowy, który dzwoni i potwierdza przyjęcie leków), persony (opiekun / podopieczny), demo-story dla jury, bank pomysłów.

3. **`docs/01-mvp-scope.md`** — MoSCoW: MUST (rutyny → schedulowane połączenia Twilio → tak/nie → transkrypcja → wynik na dashboardzie), SHOULD (retry, e-mail do opiekuna, przycisk "dzwonię teraz"), COULD (LLM w rozmowie, SMS), WON'T (rejestracja podopiecznych, mobile, płatności). Kryteria sukcesu POC + checklista demo.

4. **`docs/02-architecture.md`** — diagram komponentów (mermaid): React → FastAPI → Postgres → Redis → Celery worker+beat → Twilio (+Mailpit). Sekwencja życia połączenia: materializer → dispatcher → `place_call` → Twilio → webhooki TwiML → wynik → eskalacja. Walidacja podpisu Twilio na webhookach, publiczny URL (ngrok / deploy), lista env vars.

5. **`docs/03-data-model.md`** — encje: `Ward` (podopieczny, telefon E.164), `Medication`, `Routine` (status draft/approved — zatwierdzenie bramkuje schedulowanie), `RoutineItem`, `RoutineDependency`, `CallTask`, `Call`, `CallTurn` (transkrypcja), `CallResult` (took/not_taken/unclear), `EscalationEvent`. State machine'y + ERD (mermaid).

6. **`docs/04-user-stories.md`** — 6 epików z dużymi user stories i kryteriami akceptacji (Given/When/Then): Auth, Podopieczni CRUD, Leki i rutyny (+zależności, zatwierdzanie), Call engine, Dashboard wyników i transkrypcji, Eskalacja i powiadomienia.

7. **`docs/05-api-spec.md`** — tabela endpointów `/api/v1`: wards, medications, routines (+approve), call-tasks, calls, results, test-call; webhooki `POST /twilio/voice/{task_id}` i `/twilio/status` (auth = podpis Twilio); przykładowe payloady.

8. **`docs/06-call-flow.md`** — decyzja odroczona, więc udokumentowane **dwie opcje**: A) TwiML `<Gather>` speech pl-PL + hints ["tak","nie"] (rekomendowana na MVP), B) ConversationRelay + LLM (stretch). Wspólny interfejs `ConversationEngine` — podmienialny. Polski skrypt rozmowy, parsowanie tak/nie, timeouty, schemat JSON transkrypcji.

9. **`docs/07-scheduling-escalation.md`** — Celery beat: materializer rutyn → CallTask; dispatcher co minutę z lockiem Redis; polityka po połączeniu (domyślnie: wziął → koniec; nie/nie odbiera → retry po 15 min max 2 → eskalacja e-mailem do opiekuna). Proste domyślne, konfigurowalne.

10. **`docs/08-hackathon-plan.md`** — rozpiska 21h dla 6 osób: role (BE-core, BE-infra, Twilio-integracja, FE-dashboard, FE-builder, QA/demo/PM), tabela tasków (zadanie, owner, zależności, szacunek), kamienie milowe (T+1h setup Twilio z checklistą i weryfikacją numeru demo; T+8h pierwszy E2E call; T+13h pełna pętla z eskalacją; T+17h freeze; reszta = próba demo + buffer), rejestr ryzyk z planem B.

11. **`docs/09-roadmap.md`** + **`docs/10-decisions.md`** — post-MVP (LLM i pytania podchwytliwe, analityka adherencji, SMS/WhatsApp, portal rodziny, RODO) + dziennik decyzji (ADR) i otwarte pytania.
